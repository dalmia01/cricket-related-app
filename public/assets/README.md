Assets folder for static icons and background images.

Placement:
- Put icons under `/assets/icons`
- Put background images under `/assets/backgrounds`

Usage (Next.js):
- Reference images from the `public` root, e.g. `/assets/icons/icon-ball.svg` or `/assets/backgrounds/bg-hero.svg`.

Guidelines:
- Prefer SVG for icons when possible.
- Use descriptive filenames (kebab-case).
- Keep small thumbnails under `icons`, large hero images under `backgrounds`.
